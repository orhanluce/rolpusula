# Katkı

Kurmaca verilerle küçük ve test edilebilir değişiklikler önerin.
Gerçek CV, iletişim, API anahtarı, indirilen başvuru paketi veya tarayıcı profilini
issue/PR'ye eklemeyin. Yeni izin veya veri aktarımı ayrı tasarım incelemesi gerektirir.

    npm test
    npm run check
    npm run build

Arayüz değişiyorsa tarayıcı testini, dar ekranda taşmayı ve klavye kullanımını kontrol edin.
Portal sorguları normal CI'a ağ erişimi eklememeli; canlı testleri ayrı çalıştırın.
Upstream şablon güncellemesinde provenance ve lisansları koruyun.
Sadece test geçsin diye kişiselleştirme/sızıntı kontrollerini zayıflatmayın.
